# HomeCare AI 가상 RAG 테스트 데이터

이 폴더의 회사 정책, 오류 코드, 원인, 점검 절차는 모두 테스트를 위해 만든 **가상의 데이터**입니다. 실제 제조사의 매뉴얼이나 실제 제품의 수리 지침으로 사용하지 마세요.

- 가상 회사: 홈케어 테스트 가전
- 문서 버전: `1.0`
- 작성일: `2026-10-11`
- 범위: 기존 서비스의 제품 카테고리별 고객 상담 자료
- 구성: 카테고리별 Markdown 파일 5개, 상담 항목 20개, 평가 질문 26개

## 파일 구성

| 카테고리 | 매뉴얼 파일 | 문서 ID |
| --- | --- | --- |
| `AIR_CONDITIONER` | [manuals/air-conditioner.md](manuals/air-conditioner.md) | `HC-AC-001` ~ `HC-AC-004` |
| `REFRIGERATOR` | [manuals/refrigerator.md](manuals/refrigerator.md) | `HC-RF-001` ~ `HC-RF-004` |
| `WASHER` | [manuals/washer.md](manuals/washer.md) | `HC-WS-001` ~ `HC-WS-004` |
| `DRYER` | [manuals/dryer.md](manuals/dryer.md) | `HC-DR-001` ~ `HC-DR-004` |
| `DISHWASHER` | [manuals/dishwasher.md](manuals/dishwasher.md) | `HC-DW-001` ~ `HC-DW-004` |

각 `## HC-...` 항목은 독립적인 상담 근거입니다. 항목마다 카테고리, 버전, 오류 코드, 증상, 가능한 원인, 고객 점검 절차, 상담 전환 기준을 담았습니다. 상세 모델 구분은 없습니다.

추후 검색용으로 나눌 때는 `## HC-...` 항목 단위로 읽으면 됩니다. 검색 결과에 문서 ID, 카테고리, 제목, 버전, 파일 경로를 함께 보존하면 답변의 근거를 확인하기 쉽습니다. 이 폴더는 데이터만 제공하며 문서 적재, 임베딩, 검색, API 연동은 구현하지 않습니다.

## 테스트 질문

[evaluation.jsonl](evaluation.jsonl)은 한 줄에 JSON 객체 하나가 있는 UTF-8 파일입니다.

| 필드 | 의미 |
| --- | --- |
| `id` | 평가 질문 ID |
| `category` | 사용자가 선택한 기존 제품 카테고리. 미선택은 `null` |
| `question` | 사용자 질문 |
| `expected_behavior` | `grounded`: 근거 기반 안내, `escalate`: 고객 점검 중단 및 상담 전환, `clarify`: 정보 확인 질문, `not_found`: 근거 없음 안내 |
| `expected_document_ids` | 답변의 근거로 사용할 상담 항목 ID. 빈 배열은 답변 근거를 지정할 수 없는 경우 |
| `expected_points` | 답변에서 확인할 내용. 완전히 같은 문장을 요구하는 정답은 아님 |

평가할 때는 맞는 항목을 검색했는지와 그 항목에 근거해 답했는지를 각각 확인하세요. `expected_document_ids`는 필요한 근거 목록이며, 검색된 모든 문서의 순위나 개수를 고정하지 않습니다. 고객 점검을 중단해야 하는 사례에서는 일반 점검보다 중단 안내가 먼저 나와야 합니다.

## 바로 입력해 볼 테스트 프롬프트 5개

웹 화면에서 각 테스트마다 **새 상담 시작**을 누르고 아래 카테고리를 선택한 뒤 질문을 입력하세요. 답변 내용과 답변 아래 **검색 근거**를 함께 확인합니다.

| 번호 | 선택할 카테고리 | 입력할 프롬프트 | 기대 동작과 근거 |
| --- | --- | --- | --- |
| 1 | 세탁기 (`WASHER`) | 세탁기에 HC-E01이 뜨고 물이 안 들어와요. 제가 먼저 확인할 수 있는 방법을 알려주세요. | 급수 지연으로 안내하고 수도꼭지, 단수 여부, 외부 급수 호스를 확인하도록 답변합니다. 근거에 `HC-WS-001`이 포함되어야 합니다. |
| 2 | 냉장고 (`REFRIGERATOR`) | 냉장고에 HC-E01이 뜨면서 계속 삐삐 울려요. 문을 닫았는데도 그러면 무엇을 확인해야 하나요? | `HC-RF-001`을 근거로 식품 용기, 서랍, 문 패킹을 확인하고 문을 닫은 뒤 1분 후 경고를 확인하도록 안내합니다. 같은 코드라도 세탁기의 급수 지연과 혼동하지 않아야 합니다. |
| 3 | 에어컨 (`AIR_CONDITIONER`) | 오류 코드는 없는데 에어컨에서 찬 바람이 안 나와요. 리모컨에서 무엇을 확인해야 하나요? | 오류 코드 없이도 `HC-AC-003`을 검색해 냉방 모드, 가상 점검 설정 24°C·풍량 자동, 10분 뒤 확인을 안내합니다. 냉매 부족으로 단정하지 않아야 합니다. |
| 4 | 건조기 (`DRYER`) | 건조기에 HC-E01이 뜨고 옷도 덜 말랐어요. 보풀도 많고 수건이랑 얇은 옷을 섞어 넣었어요. 무엇부터 확인해야 하나요? | `HC-DR-001`과 `HC-DR-003`을 근거로 보풀 필터 점검과 두꺼운 옷·얇은 옷 분리, 적재량·코스 조정을 함께 안내합니다. |
| 5 | 식기세척기 (`DISHWASHER`) | 식기세척기에 HC-E99가 떴어요. 무슨 부품이 고장 났고 어떻게 수리하면 되나요? | 매뉴얼에 없는 코드임을 알리고 표기·증상 확인 또는 수리 상담을 안내합니다. 고장 부품이나 수리 절차를 만들어 답하지 않아야 하며, 검색 근거는 비어 있어야 합니다. |

검색 근거에 추가 문서가 표시될 수 있습니다. 문서가 검색됐다는 사실만으로 답변이 정확한 것은 아니므로, 실제 안내가 해당 본문에 있는 내용인지도 확인하세요.

## 의도한 테스트 조건

- `HC-E01`은 5개 카테고리에 공통으로 등장하지만 의미와 절차가 다릅니다. 카테고리 없이 오류 코드만 받은 경우 제품을 먼저 확인해야 합니다.
- `HC-E04`는 세탁기와 식기세척기에 공통으로 등장합니다. 제품에 맞는 매뉴얼을 근거로 답해야 합니다.
- 오류 코드 없이 증상을 설명하는 질문, 구어체 질문, 두 가지 증상을 함께 묻는 질문을 포함합니다.
- 선택한 카테고리와 질문 속 제품이 다르면 제품을 확인해야 합니다.
- `HC-E99`, TV, 수리 가격, 보증 기간은 자료에 없습니다. 문서에 없는 원인·가격·정책을 만들어 답하지 않아야 합니다.
- 실제 예약 시스템, 수리 비용표, 보증 정책, 서비스 연락처는 포함하지 않습니다. 상담 전환 안내가 실제 접수 완료를 의미하지 않습니다.

이 데이터만으로 실제 제품에 대한 답변 품질을 평가할 수는 없습니다. RAG의 검색, 카테고리 구분, 근거 표시, 정보 부족 대응을 확인하는 용도입니다.
