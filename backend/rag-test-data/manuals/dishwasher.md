# 식기세척기 고객 상담 매뉴얼 — 가상 테스트 자료

가상 회사: 홈케어 테스트 가전. 아래 내용은 실제 제품 수리 지침이 아닙니다.

## HC-DW-001 | HC-E01: 급수 지연

- 문서 ID: `HC-DW-001`
- 카테고리: `DISHWASHER`
- 문서 버전: `1.0`
- 오류 코드: `HC-E01`
- 검색 표현: 식기세척기 E01, 물 안 들어옴, 세척 시작 안 됨, 급수 경고

### 증상과 가능한 원인

세척을 시작한 뒤 `HC-E01`이 표시되고 물이 충분히 들어오지 않습니다. 이 가상 제품에서 코드는 급수 지연을 뜻합니다. 제품 급수 수도꼭지가 닫혀 있거나 외부 급수 호스가 눌려 있을 수 있습니다.

### 고객 점검 절차

1. 운전을 정지합니다.
2. 안전하게 접근할 수 있는 제품 급수 수도꼭지가 열려 있는지 확인합니다.
3. 다른 수도의 물 공급 상태를 확인합니다.
4. 외부에서 보이는 급수 호스의 눌림만 확인합니다. 빌트인 제품을 꺼내거나 호스를 분리하지 않습니다.
5. 문제가 해소되면 문을 닫고 세척을 한 번 재개합니다.

### 상담 전환 기준과 제한

수도와 외부 호스에 문제가 없는데 코드가 반복되거나 호스에 접근할 수 없으면 수리 상담을 안내합니다. 제품 하부 덮개와 내부 급수 밸브를 열지 않습니다.

## HC-DW-002 | HC-E04: 배수 지연

- 문서 ID: `HC-DW-002`
- 카테고리: `DISHWASHER`
- 문서 버전: `1.0`
- 오류 코드: `HC-E04`
- 검색 표현: 식기세척기 E04, 바닥에 물 남음, 세척 후 물 안 빠짐, 배수 경고

### 증상과 가능한 원인

세척 후 제품 내부 바닥에 물이 남고 `HC-E04`가 표시됩니다. 이 가상 제품에서 코드는 배수 지연을 뜻합니다. 고객용 거름망에 음식물 찌꺼기가 쌓였거나 외부 배수 호스가 눌렸을 수 있습니다.

### 고객 점검 절차

1. 운전을 정지하고 내부가 충분히 식을 때까지 기다립니다.
2. 전원 연결부와 손이 마른 상태에서 전원을 분리합니다.
3. 나사 없이 탈착되는 고객용 거름망만 꺼내 흐르는 물로 씻고 다시 장착합니다.
4. 안전하게 보이는 외부 배수 호스의 눌림을 확인합니다. 빌트인 제품을 꺼내지 않습니다.
5. 주변 누수가 없다면 문을 닫고 전원을 연결한 뒤 배수 기능을 한 번 실행합니다.

### 상담 전환 기준과 제한

물이 계속 남거나 바닥으로 새면 재시도하지 않고 수리 상담을 안내합니다. 내부 배수 펌프를 열거나 배관에 도구를 넣지 않습니다. 세탁기의 `HC-E04`에는 식기세척기 거름망 청소 절차를 적용하지 않습니다.

## HC-DW-003 | 코드 없음: 음식물이 남음

- 문서 ID: `HC-DW-003`
- 카테고리: `DISHWASHER`
- 문서 버전: `1.0`
- 오류 코드: 없음
- 검색 표현: 그릇에 음식물 남음, 잘 안 씻김, 세척 불량, 분사 날개 막힘

### 증상과 가능한 원인

오류 코드 없이 세척이 끝났지만 그릇에 음식물이 남아 있습니다. 그릇이 겹쳐 물이 닿지 않거나 긴 식기가 분사 날개의 회전을 막는 경우를 먼저 확인합니다.

### 고객 점검 절차

1. 운전이 끝나고 내부가 충분히 식은 뒤 문을 엽니다.
2. 큰 음식물 찌꺼기를 제거하고 그릇이 겹치지 않도록 다시 배치합니다.
3. 긴 식기가 분사 날개를 막지 않는지 확인합니다.
4. 식기세척기 전용 세제를 사용했는지 확인하고 식기의 사용 가능 표시와 오염 정도에 맞는 코스를 선택합니다.

### 상담 전환 기준과 제한

배치와 코스를 조정해도 세척 불량이 반복되면 수리 상담을 안내합니다. 일반 손 설거지용 세제를 넣거나 분사 장치를 분해하도록 안내하지 않습니다.

## HC-DW-004 | 코드 없음: 그릇에 흰 자국

- 문서 ID: `HC-DW-004`
- 카테고리: `DISHWASHER`
- 문서 버전: `1.0`
- 오류 코드: 없음
- 검색 표현: 컵 흰 얼룩, 흰 가루, 물자국, 세제 잔여물, 린스

### 증상과 가능한 원인

세척 후 그릇과 컵에 흰 자국이 남습니다. 이 가상 매뉴얼에서는 물의 미네랄 흔적과 과다한 세제 사용을 가능한 원인으로 봅니다. 설명만으로 자국의 성분을 확정할 수 없습니다.

### 고객 점검 절차

1. 식기세척기 전용 세제를 사용했는지 확인합니다.
2. 세제 포장에 적힌 사용량을 따르고 임의로 양을 늘리지 않습니다.
3. 이 가상 제품의 린스 보충 표시가 있는 경우 식기세척기 전용 린스를 보충합니다.
4. 다음 세척에서도 자국이 반복되는지 확인합니다.

### 상담 전환 기준과 제한

적정 세제량과 린스 상태를 확인해도 자국이 반복되면 수리 상담을 안내합니다. 자국이 해롭지 않다고 보장하거나 표백제·산성 세정제를 섞어 사용하라고 안내하지 않습니다. 음식물 찌꺼기 문제는 `HC-DW-003`과 구분합니다.
