# HomeCare AI

> 등록한 가전 제품과 증상을 바탕으로 자가점검 단계, 보증, 예상 수리비, 공식 A/S 경로를 안내하는 상담 서비스
> 지원 품목: 세탁기 · 건조기 · 냉장고(김치냉장고 포함) · 식기세척기

## 구성

```text
React 프론트엔드
 → Spring Boot 백엔드(OpenAI 모델을 쓰는 상담 Agent)
 → Java MCP 클라이언트
 → Python FastMCP 서버
 → Spring 도메인 API·정적 자료
```

### 담당 역할 (Sjoneon)

> 팀장 · 서비스 기획·설계 총괄

- 기능명세·시퀀스·ERD 작성
- Agent·MCP·RAG 설계·개발
- 분석·화면 검토·평가 개선

**세부 내용**: 이 저장소의 상담 기능(제품 확인, 자가 점검, 보증, 예상 수리비, A/S 연결)에서 맡은 일

**1. 지원 범위·상담 동작 결정**

- 지원 품목: 세탁기·건조기·냉장고(김치냉장고 포함)·식기세척기 4품목으로 한정, 에어컨 제외(2026-10-13)
- 제품 정보: 상담 화면의 별도 보증 입력 대신 등록 제품 정보 사용(2026-10-14)
- 위험 확인: 위험 판단 뒤 대화 안의 예/아니요 버튼으로 실제 위험 여부 확인(2026-10-14)
- 보증 계산: 보증 시작일을 등록 구매일로 계산(2026-10-15)
- 응답 구성: 목표 상담 흐름도 제시, 응답마다 카드 하나로 구성
- 결정별 이유와 구현 위치: [상담 설계 결정 기록 3장](docs/mcp/consultation_design_decisions.md#3-설계-결정)

**2. 코드 리뷰**

- 구조·함수·변수 이름·로직 검토

**3. 실제 상담 출력 검수와 문제 제기**

| 날짜 | 지적한 문제 | 반영한 조치 |
| --- | --- | --- |
| 2026-10-14 | 제거한 제품 선택 영역이 다시 나타남, 자가조치·수리비 누락 | 제품 선택 영역을 다시 넣지 않고 등록 제품의 DB 정보 사용 |
| 2026-10-14 | 세탁기 진동 질문에 무관한 침수·급수 근거, 고객 화면에 원본 JSON 노출 | 모델·품목 필터와 증상 어휘·임베딩 검색, 고객용 필드만 표시 |
| 2026-10-15 | 냉장고 답변이 대부분 "확인 필요", 센터 3곳을 전국 조회처럼 사용 | 설명서 확인 항목 안내, 구매일 기준 보증, 공식 출장 접수 연결 |

- 상세: [검수에서 찾은 문제](docs/mcp/consultation_design_decisions.md#4-검수에서-찾은-문제)

**4. 평가 기준 제시**

- 분류나 도구 호출이 성공해도 질문에 맞는 답이 나오지 않으면 통과로 보지 않는 기준 제시(2026-10-15)
    - 결과: 분류·도구 결과와 답변 적합성을 따로 판정하는 [답변 적합성 기준](docs/mcp/consultation_answer_rubric.json)
- 고정 사례만으로 낸 평가 수치의 편향 가능성 지적(2026-10-15)
- 평가 기록: [실제 상담 평가와 회귀 검증](docs/mcp/consultation_validation.md)

**5. 단계별 개발·커밋 관리**

- 미완성 기능을 8단계로 나누어 진행(2026-10-14~15)
    1. 제조사 자료 구조화
    2. 검색 연결
    3. 증상 해석과 대화 상태
    4. 근거 기반 답변 구성
    5. 조건 확인과 자가조치
    6. 원인 후보·보증·비용·A/S 연결
    7. 상담 화면 표시
    8. 실제 상담 평가
- 단계마다 결과를 확인한 뒤 기능별로 커밋하고 통합 브랜치(`mcp_feature_integration`)에 반영
- 단계별 기록: [MCP 도구 구현 7장](docs/mcp/mcp_implementation.md#7-단계별-기록)
