# HomeCare AI 프론트엔드

흰색·버건디 색상, 제품 선택 카드, 상담 내역 사이드바, 하단 입력창을 적용했습니다.
회원가입·로그인 후 제품 카테고리를 선택하고 질문을 입력하면 Spring Boot 백엔드에 보내고 답변을 표시합니다.

## 로컬 실행

프로젝트 루트에서 터미널 두 개를 사용합니다.

첫 번째 터미널 — 백엔드 실행:

MySQL의 `project_db`와 `backend/.env`의 `JWT_SECRET`이 필요합니다.
현재 로컬 설정에는 JWT 서명 키가 추가되어 있습니다. 자세한 설정은 `backend/README.md`를 참고하세요.

```bash
cd backend
./gradlew bootRun
```

두 번째 터미널 — 프론트엔드 실행:

```bash
cd frontend
npm ci
npm run dev
```

이미 의존성이 설치되어 있다면 `npm ci`는 생략할 수 있습니다.
브라우저에서 **http://127.0.0.1:5173**을 엽니다.

`vite.config.js`에서 `/api` 요청을 `http://127.0.0.1:8080`으로 프록시합니다.
브라우저는 프론트엔드와 같은 주소로 요청하므로 백엔드의 CORS 설정을 추가할 필요가 없습니다.
백엔드 포트를 변경했다면 프록시 주소도 변경하고 프론트엔드를 다시 실행하세요.
기존 Docker 서버와 IPv6 주소가 섞이지 않도록 명시적으로 `127.0.0.1`을 사용합니다.

API 키는 기존 `backend/.env`에서 백엔드만 읽습니다. 프론트엔드에는 키를 넣지 않습니다.

## 사용

- 처음에는 로그인 화면이 표시됩니다. 계정이 없다면 **회원가입**으로 전환해 가입한 뒤 로그인합니다.
- 로그인 성공 시 이메일과 상담 화면을 표시합니다. 잘못된 비밀번호나 중복 이메일은 오류로 안내합니다.
- 새 상담에서는 **에어컨·냉장고·세탁기·건조기·식기세척기** 중 카테고리를 선택합니다. 상세 모델 선택과 사진 첨부는 없습니다.
- 증상을 입력하고 **상담 시작** 또는 **Enter**로 전송합니다. 카테고리 미선택 또는 빈 입력은 전송할 수 없습니다.
- 제품별 예시 질문을 누르면 해당 카테고리와 입력 내용을 채워줍니다. 전송 전 수정할 수 있습니다.
- **Shift + Enter**는 줄바꿈이며, 한글 조합 중의 Enter는 전송하지 않습니다.
- 최대 4,000자까지 입력할 수 있고 응답을 기다리는 동안 중복 전송을 막습니다.
- 요청 실패 시 오류를 표시하고 입력을 복원하여 다시 전송할 수 있습니다.
- 성공한 질문과 답변은 계정별로 MySQL에 저장합니다. 첫 질문의 앞 50자를 대화 제목으로 사용합니다.
- **내 상담 내역**에서 품목·제목·갱신 시간을 확인하고, 상담을 선택해 전체 질문·답변을 조회합니다.
- 내역은 오늘·어제·이전 상담으로 구분하며, 제목과 카테고리로 검색할 수 있습니다.
- 선택한 대화에서 질문을 보내면 해당 대화에 추가하며, 목록은 최근 갱신된 대화가 먼저 표시됩니다.
- **새 상담 시작**은 제품 선택 화면으로 전환합니다. 저장된 기록은 유지하며, 첫 질문이 성공하면 새 상담을 저장합니다.
- 좁은 화면에서는 상단 **상담 내역 열기** 버튼으로 내역을 열고, 닫기 버튼 또는 Escape로 닫을 수 있습니다.
- **로그아웃**은 토큰과 현재 화면의 대화를 지우고 로그인 화면으로 돌아갑니다. DB의 기록은 유지됩니다.
- 목록 조회 실패 시 **다시 불러오기**로 재시도할 수 있습니다.

로그인 토큰은 React 상태에만 보관하며 새로고침하면 다시 로그인해야 합니다.
같은 계정으로 로그인하면 DB에 저장한 이전 대화를 다시 조회할 수 있습니다.
선택한 카테고리는 DB에 저장하고 후속 질문에서도 AI에 전달합니다. 상담 시작 후 품목은 변경하지 않습니다.
카테고리 기능 추가 전의 기록은 **일반 상담**으로 표시하고 그대로 이어서 질문할 수 있습니다.
기능 추가 전에 화면에만 표시된 대화는 복원할 수 없습니다.
토큰은 localStorage, sessionStorage, 쿠키에 저장하지 않습니다.
채팅·대화 조회 요청에는 `Authorization: Bearer <accessToken>`을 전달하며,
인증 오류(401)가 반환되면 로그인 화면으로 돌아갑니다.
백엔드가 이전 대화를 기억하지 않으므로 각 질문은 독립적으로 처리됩니다.
AI 답변은 일반 텍스트로 표시합니다.
현재는 일반 LLM 답변이며 수리 매뉴얼 RAG, 예상 수리비, 보증 판정, 사진 인식은 구현하지 않았습니다.
참고 프로젝트의 로컬 기록 저장이나 제안 API 대신 기존 `/api/chat`, `/api/conversations`와 계정별 MySQL 저장을 사용합니다.

## 빌드

```bash
npm run build
npm run lint
```

결과는 `dist/`에 생성됩니다. API 프록시는 Vite 개발 서버에만 적용되므로,
빌드 결과를 별도로 서비스할 때는 `/api` 요청을 백엔드로 전달하는 설정이 필요합니다.

설정 참고: [Vite 개발 서버 프록시](https://vite.dev/config/server-options.html#server-proxy).
