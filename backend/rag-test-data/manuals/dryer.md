# 건조기 고객 상담 매뉴얼 — 가상 테스트 자료

가상 회사: 홈케어 테스트 가전. 아래 내용은 실제 제품 수리 지침이 아닙니다.

## HC-DR-001 | HC-E01: 보풀 필터 막힘

- 문서 ID: `HC-DR-001`
- 카테고리: `DRYER`
- 문서 버전: `1.0`
- 오류 코드: `HC-E01`
- 검색 표현: 건조기 E01, 보풀 필터, 건조 오래 걸림, 필터 경고

### 증상과 가능한 원인

`HC-E01`이 표시되며 건조 시간이 길어집니다. 이 가상 제품에서 코드는 보풀 필터에 보풀이 쌓여 공기 흐름이 줄었다는 뜻입니다.

### 고객 점검 절차

1. 운전을 정지하고 제품이 충분히 식을 때까지 기다립니다.
2. 플러그와 손이 마른 상태에서 전원을 분리합니다.
3. 고객이 탈착할 수 있는 보풀 필터를 꺼내 부드러운 솔로 보풀을 제거합니다.
4. 필터를 제자리에 장착하고 덮개를 닫은 뒤 운전을 한 번 재개합니다.

### 상담 전환 기준과 제한

필터를 정리했는데도 코드가 반복되면 수리 상담을 안내합니다. 필터 없이 운전하거나 내부 열교환기와 전기 부품을 분해하지 않습니다. 타는 냄새나 연기가 있으면 이 점검을 진행하지 않고 `HC-DR-004`의 사용 중단 안내를 우선합니다.

## HC-DR-002 | HC-E06: 물통 가득 참

- 문서 ID: `HC-DR-002`
- 카테고리: `DRYER`
- 문서 버전: `1.0`
- 오류 코드: `HC-E06`
- 검색 표현: 건조기 E06, 물통 비움, 물통 가득 참, 건조 중 멈춤

### 증상과 가능한 원인

물통 사용 방식으로 운전하는 가상 건조기에서 `HC-E06`이 표시되고 건조가 멈춥니다. 코드는 응축수가 모이는 물통이 가득 찼다는 뜻입니다.

### 고객 점검 절차

1. 운전을 정지합니다.
2. 고객용 물통을 천천히 꺼내 물을 비웁니다.
3. 물통을 끝까지 장착하고 운전을 한 번 재개합니다.
4. 물통이 비어 있는데도 경고가 반복되는지 확인합니다.

### 상담 전환 기준과 제한

빈 물통을 제대로 장착했는데도 코드가 유지되면 수리 상담을 안내합니다. 외부 배수 호스를 사용하는 방식이라면 이 항목만으로 원인을 확정할 수 없으므로 배수 방식을 먼저 확인합니다. 물통 감지 센서를 분해하지 않습니다.

## HC-DR-003 | 코드 없음: 건조 후 옷이 축축함

- 문서 ID: `HC-DR-003`
- 카테고리: `DRYER`
- 문서 버전: `1.0`
- 오류 코드: 없음
- 검색 표현: 옷이 안 마름, 건조 후 축축함, 수건 덜 마름, 건조 약함

### 증상과 가능한 원인

오류 코드 없이 건조가 끝났지만 일부 옷이 축축합니다. 두꺼운 수건과 얇은 옷을 함께 넣었거나 세탁물이 많이 들어간 경우, 낮은 건조 강도를 선택한 경우를 확인합니다.

### 고객 점검 절차

1. 두꺼운 세탁물과 얇은 세탁물을 나눕니다.
2. 통 안에서 세탁물이 움직일 수 있도록 적재량을 줄입니다.
3. 의류의 건조기 사용 가능 표시를 확인한 뒤 해당 의류에 맞는 코스와 건조 강도를 선택합니다.
4. 보풀 필터 경고가 있으면 `HC-DR-001`을 함께 참고합니다.

### 상담 전환 기준과 제한

적재와 코스를 조정해도 건조가 되지 않으면 수리 상담을 안내합니다. 모든 의류에 높은 온도나 최고 강도를 적용하라고 답하지 않습니다. 타는 냄새나 연기가 있으면 추가 건조를 시도하지 않습니다.

## HC-DR-004 | 코드 없음: 타는 냄새 또는 연기

- 문서 ID: `HC-DR-004`
- 카테고리: `DRYER`
- 문서 버전: `1.0`
- 오류 코드: 없음
- 검색 표현: 건조기 탄 냄새, 타는 냄새, 연기, 과열 의심

### 증상과 가능한 원인

운전 중 타는 냄새가 나거나 연기가 보입니다. 이 가상 매뉴얼은 이를 사용 중단이 필요한 상황으로 분류합니다. 설명만으로 보풀, 의류 또는 전기 부품 중 어느 것이 원인인지 확정할 수 없습니다.

### 고객 점검 절차

1. 안전하게 조작할 수 있다면 즉시 운전을 정지합니다.
2. 연기나 열이 있는 제품에 접근하거나 뜨거운 본체와 플러그를 만지지 않습니다.
3. 제품 주변에서 떨어져 안전을 확보합니다. 연기나 불꽃이 계속되면 수리 상담보다 긴급 도움 요청을 우선합니다.
4. 상황이 진정되어도 다시 운전하지 않고 수리 상담을 요청합니다.

### 상담 전환 기준과 제한

필터 청소나 재가동을 고객 해결책으로 제시하지 않습니다. 내부 분해 점검과 전기 부품 조작은 안내하지 않습니다. 이 자료에는 실제 긴급 연락처나 예약 접수 시스템이 없습니다.
