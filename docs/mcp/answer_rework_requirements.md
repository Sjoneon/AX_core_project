# 상담 답변 개편 요구사항

작성일: 2026-10-15. 상태: 요구 확인 단계(구현 전). 기준 사례: S836MEE022 / "냉장고가 시원하지 않아요."

## 1. 요구 요약

1. 고객이 알 필요 없는 문구와 카드는 표시하지 않는다.
2. 설명서의 확인 항목은 자가 점검 단계로 번호를 붙여 안내한다. 설명서 링크는 주지 않는다.
3. 자가 점검 방법이 없거나 점검 후에도 해결되지 않으면, 그 사실을 한 줄로 알리고 예상 총 수리비를 안내한다.

## 2. 상담 흐름

### 1단계: 증상 입력

고객: "냉장고가 시원하지 않아요."

```text
냉장고가 시원하지 않은 증상으로 확인했어요. 아래 순서대로 확인해 주세요.

1. 정전이 아닌지, 전원 플러그가 연결되어 있는지 확인해 주세요.
2. 보관 온도 설정을 확인해 주세요.
3. 문이 제대로 닫혀 있는지 확인해 주세요.
4. 식품 배치를 확인해 주세요.
5. 냉장고 주위 설치 환경을 확인해 주세요.

확인한 뒤에도 시원하지 않나요?
[해결됐어요] [여전히 안 돼요]
```

- 단계 내용은 설명서 확인 항목(현재 검토 목록 16개)만 사용한다. 설명서에 없는 내용은 덧붙이지 않는다.
- 한 항목에 여러 대상이 있으면 나눈다. 예: "보관 온도, 문 닫힘, 식품 배치와 주위 설치 환경" → 2~5번.
- 분해·부품 교체·청소처럼 확인이 아닌 조치는 단계에 넣지 않는다(현재 필터 유지).

### 2단계-A: "해결됐어요"

```text
해결되어 다행이에요. 같은 증상이 다시 생기면 새 상담에서 알려 주세요.
```

### 2단계-B: "여전히 안 돼요"

```text
더 해 볼 수 있는 자가 점검 방법이 없어요. 점검이 필요합니다.

예상 총 수리비: 약 ○○원 ~ ○○원 (부품비·기술료·출장비 포함, 참고용)
보증: 구매일 2026-05-05 기준 보증기간 안(만료 2027-05-05). 무상 수리 여부는 점검 때 확정됩니다.

[LG 출장 서비스 예약] [고객센터 1544-7777]
```

### 자가 점검 방법이 없는 증상

1단계에서 바로 2단계-B 형식으로 답한다. 첫 줄만 바뀐다.

```text
이 증상은 직접 해 볼 수 있는 점검 방법이 없어요. 점검이 필요합니다.
```

## 4. 예상 총 수리비

- 금액 출처는 `parts.json`(v3 비용표)이다. 값은 부품비·기술료·평일 출장비를 합친 총액이다.
- 현재 증상과 부품 그룹을 잇는 자료가 없다. 증상별 후보 부품 그룹 매핑을 새로 만들어야 한다.
- 현재 금액 표시를 막는 규칙 세 가지를 바꿔야 한다.
  1. 비용을 물었을 때만 계산한다.
  2. 증상과 부품의 연결 근거가 있어야 한다.
  3. 국내 같은 부품 사례가 3건 이상이어야 한다.

냉장고 비용 그룹(참고, 매핑 미정):

## 5. 바뀌는 기존 원칙

| 기존 | 변경 |
|---|---|
| 승인 계획(`approved-plans.json`)에 있는 단계만 자가조치로 안내 | 검토 목록을 통과한 설명서 확인 항목도 자가 점검 단계로 안내 |
| 비용은 고객이 물었을 때만 안내 | 자가 점검이 없거나 실패하면 비용을 묻지 않아도 안내 |
| 답변에 제조사 근거 링크 표시 | 화면에서 제거(내부 저장은 유지) |

관련 문서 [repair_followup.md](repair_followup.md), [grounded_answer_generation.md](grounded_answer_generation.md)의 해당 원칙도 함께 고친다.

## 6. 결정이 필요한 것

1. 증상별 후보 부품 그룹을 누가, 어떤 근거로 정할지.
2. 수리비 표시 방식: 후보 전체를 한 범위로(최저~최고) 보여 줄지, 후보 그룹별로 나눠 보여 줄지.
3. 사례 3건 미만 그룹의 금액도 표시할지.
4. 상담원 전달 요약을 완전히 없앨지, "요약 복사" 버튼만 남길지.
