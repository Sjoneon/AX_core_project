# 수리비 정규화 패키지 (v3, 2026-10-08)

실행 순서: python3 normalize.py → python3 model.py → python3 model_v2.py → python3 model_v3.py

- normalize.py : 해외 가격 → 한국 원화(부가세 10% 포함), 국내 후기 → 오늘가치(물가·현재 출장비)
- model.py     : v1. 부품비 보정계수(미국 0.31, 유럽 0.95) + 제품군별 기술료
- model_v2.py  : 기술료를 작업 난이도 등급(T1 전장·센서 / T2 기계부품 / T3 대분해·냉매)으로 분리
                 근거: LG전자 한국 '수리 난이도(시간)에 따른 순수 기술료', LG전자 중국 대·중·소수리 요금표
- model_v3.py  : v2 예측을 국내 같은 부품 실제 총액 중앙값 쪽으로 축소(가중치 n/(n+2)) + 80% 경험적 범위(×/÷1.359)

검증(국내 LG 유상 20건, 하나씩 빼고 예측)
| 모델 | ±5% | ±10% | ±20% | 중앙 절대오차 | 범위 적중 |
| v1 | 2 | 5 | 12 | 17.0% | 65% |
| v3 | 6 | 10 | 11 | 11.2% | 80% |

주의: 등급 배정·축소 강도·범위 폭을 같은 20건으로 골랐으므로 새 사례에서는 오차가 더 클 수 있음.
