# 세탁기 고객 상담 매뉴얼 — 가상 테스트 자료

가상 회사: 홈케어 테스트 가전. 아래 내용은 실제 제품 수리 지침이 아닙니다.

## HC-WS-001 | HC-E01: 급수 지연

- 문서 ID: `HC-WS-001`
- 카테고리: `WASHER`
- 문서 버전: `1.0`
- 오류 코드: `HC-E01`
- 검색 표현: 세탁기 E01, 물 안 들어옴, 급수 안 됨, 시작 후 멈춤

### 증상과 가능한 원인

세탁을 시작했지만 물이 충분히 들어오지 않고 `HC-E01`이 표시됩니다. 이 가상 제품에서 코드는 급수 지연을 뜻합니다. 닫힌 급수 수도꼭지, 외부 급수 호스의 꺾임, 건물의 단수 등이 가능한 원인입니다.

### 고객 점검 절차

1. 세탁을 일시 정지합니다.
2. 제품에 연결된 급수 수도꼭지가 열려 있는지 확인합니다.
3. 다른 수도에서도 물이 나오는지 확인해 단수 여부를 구분합니다.
4. 제품 외부에서 보이는 급수 호스가 꺾이거나 눌렸는지 확인합니다. 호스를 분리하지 않습니다.
5. 문제가 해소되면 운전을 한 번 재개해 급수 여부를 확인합니다.

### 상담 전환 기준과 제한

수도와 외부 호스에 문제가 없는데 코드가 다시 나오면 수리 상담을 안내합니다. 내부 급수 밸브를 열거나 분해하지 않습니다. 세탁기의 `HC-E01`은 배수 또는 탈수 불균형 코드가 아닙니다.

## HC-WS-002 | HC-E04: 배수 지연

- 문서 ID: `HC-WS-002`
- 카테고리: `WASHER`
- 문서 버전: `1.0`
- 오류 코드: `HC-E04`
- 검색 표현: 세탁기 E04, 물 안 빠짐, 배수 안 됨, 세탁통 물 남음

### 증상과 가능한 원인

세탁통에 물이 남아 있고 `HC-E04`가 표시됩니다. 이 가상 제품에서 코드는 배수 지연을 뜻합니다. 외부 배수 호스가 꺾였거나 호스 끝이 막혀 있을 수 있습니다.

### 고객 점검 절차

1. 운전을 정지합니다.
2. 바닥이 마르고 안전하게 접근할 수 있을 때만 외부 배수 호스의 꺾임과 눌림을 확인합니다.
3. 호스 끝이 물건으로 막혀 있는지 눈으로 확인합니다. 호스를 분리하거나 도구를 넣지 않습니다.
4. 외부의 눌림을 해소했고 주변에 누수가 없다면 배수 기능을 한 번 실행해 봅니다.

### 상담 전환 기준과 제한

물이 빠지지 않거나 누수가 있으면 재시도하지 않고 수리 상담을 안내합니다. 물이 남아 있는 상태에서 문을 강제로 열거나 배수 펌프·내부 필터를 분해하는 절차는 제공하지 않습니다.

## HC-WS-003 | HC-E05 또는 코드 없음: 탈수 불균형

- 문서 ID: `HC-WS-003`
- 카테고리: `WASHER`
- 문서 버전: `1.0`
- 오류 코드: `HC-E05` 또는 없음
- 검색 표현: 세탁기 E05, 탈수 덜덜, 크게 흔들림, 이불 탈수 멈춤, 빨래 한쪽 몰림

### 증상과 가능한 원인

탈수할 때 본체가 크게 흔들리거나 `HC-E05`와 함께 탈수가 멈춥니다. 이 가상 제품에서는 세탁물의 무게가 한쪽으로 몰린 상태를 뜻합니다. 무거운 한 장의 세탁물이나 과도한 적재가 가능한 원인입니다.

### 고객 점검 절차

1. 일시 정지한 뒤 세탁통이 완전히 멈추고 문 잠금이 해제될 때까지 기다립니다.
2. 세탁물을 고르게 펼칩니다. 세탁물이 너무 많다면 일부를 덜어냅니다.
3. 바닥과 본체가 안정적인지 외부에서 확인합니다. 운전 중에는 제품을 움직이지 않습니다.
4. 문을 닫고 탈수를 한 번 재개합니다.

### 상담 전환 기준과 제한

적재를 조정해도 강한 흔들림이 반복되거나 본체가 이동하면 운전을 멈추고 수리 상담을 안내합니다. 문을 강제로 열거나 회전 중인 통에 손을 넣지 않습니다. 코드 없이 같은 증상이 있어도 이 항목을 참고할 수 있습니다.

## HC-WS-004 | 코드 없음: 누수

- 문서 ID: `HC-WS-004`
- 카테고리: `WASHER`
- 문서 버전: `1.0`
- 오류 코드: 없음
- 검색 표현: 세탁기 물 샘, 바닥 물, 누수, 콘센트 옆 물

### 증상과 가능한 원인

제품 주변 바닥에 물이 고입니다. 외부 호스 연결부 또는 제품 내부 등 여러 원인이 있을 수 있지만 고객의 설명만으로 누수 지점을 확정하지 않습니다.

### 고객 점검 절차

1. 제품 사용을 즉시 중단합니다.
2. 물에 접촉하지 않는 안전한 위치에서 조작할 수 있을 때만 급수 수도꼭지를 잠급니다.
3. 콘센트나 전원선 주변이 젖었다면 플러그와 제품을 만지지 않습니다.
4. 안전한 거리에서 물이 보이는 위치와 발생 시점을 기록하고 수리 상담을 요청합니다.

### 상담 전환 기준과 제한

누수는 일반 급수·배수 재시도보다 사용 중단 안내를 우선합니다. 고객에게 전기 부품 주변을 닦거나 재가동하여 누수 위치를 찾으라고 안내하지 않습니다. 이 항목에는 내부 수리 절차가 없습니다.
